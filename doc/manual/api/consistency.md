# consistency API

## Purpose

`consistency` is a white-box test package. It exports no MoonBit items; its
content is a suite of 176 deterministic tests (26 in
`api_audit_wbtest.mbt`, 146 in `core_wbtest.mbt` and 4 in other files on the current branch) that check laws *across*
the packages of `floating`: that the binary, decimal, GDA and interval cores,
their checked wrappers and `semantic` agree
with each other and with exact `BigInt` and rational oracles. This page
records the package's role and its (empty) interface; the
[tutorial](../tutorial/consistency.md) shows how to run and extend it and the
[design page](../design/consistency.md) explains what is checked.

## Importing

Nothing can be imported from `consistency`. It is a package of the tools module
`Luna-Flow/floating-tools`; its `moon.pkg` imports the cores of the library for
white-box tests only:

```moonbit nocheck
import {
  "Luna-Flow/arithmetic" @lf_arith,
  "Luna-Flow/luna-generic" @lf_alg,
  "Luna-Flow/floating/binary",
  "Luna-Flow/floating/binary_checked",
  "Luna-Flow/floating/decimal",
  "Luna-Flow/floating/decimal_checked",
  "Luna-Flow/floating/decimal_gda",
  "Luna-Flow/floating/decimal_gda_checked",
  "Luna-Flow/floating/interval",
  "Luna-Flow/floating/interval_checked",
  "Luna-Flow/floating/def",
  "Luna-Flow/floating-tools/semantic",
  "moonbitlang/core/string",
  "moonbitlang/x/fs",
} for "wbtest"
```

## Test files

| File | Content |
| --- | --- |
| `api_audit_wbtest.mbt` | audits of public behaviour that spans packages: `def` predicates, error and context types, the decimal interchange facade (bit-exact encodings, canonical predicates, sign operations), checked compare of `binary`, generic checked traits through `Luna-Flow/arithmetic`, and the `semantic` interpretation of binary, decimal and interval values |
| `core_wbtest.mbt` | cross-package arithmetic laws: `binary` exactness on dyadics and generic trait use, `decimal` and `decimal_gda` cohort, signed-zero and NaN-payload rules (many rows taken from the official decTest suite), `interval` enclosure properties, checked-pipeline closure, and total constructors |
| `bin_coeff_migration_wbtest.mbt` | helpers that build `Binary` values from `BigInt` for the tests above |
| `clamp_fold_agreement_wbtest.mbt` | `decimal` and `decimal_gda` agree on a zero `quantize` result under `clamp` |
| `clamp_fold_rows_wbtest.mbt` | the table of rows from CPython `decimal` that the test above reads (generated by `tools/generate_clamp_fold_rows.py`) |
| `context_vectors_wbtest.mbt` | the library constructors against `testdata/context_vectors.txt`; native target only |
| `interchange_rows_wbtest.mbt` | the table of decimal interchange rows (generated by `tools/generate_interchange_rows.py`) |
| `interchange_table_wbtest.mbt` | the rows of `interchange_rows_wbtest.mbt` run against `Decimal::to_interchange_hex` and `DecimalInterchange::from_decimal` |
| `oracle_constants_wbtest.mbt` | the limits of the library against the numbers written in the oracle programs of the gates |
| `to_binary_exponent_issue468_wbtest.mbt` | `to_binary` of `decimal_gda` and of `decimal` at large decimal exponents, against the table below |
| `to_binary_large_rows_wbtest.mbt` | the table of large-exponent rows (generated by `tools/generate_to_binary_large_rows.py`) |

All tests are white-box (`*_wbtest.mbt`) and import every core package for
`wbtest` only, so the package adds nothing to any build of the library.
